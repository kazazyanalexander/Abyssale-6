⚡ PROJET : JEU D'AVENTURE TEXTUEL MULTILINGUE & INTELLIGENCE ARTIFICIELLE ⚡
🌍 Français 🌍 English 🌍 Deutsch 🌍 中文 🤖 LLM Local 🎤 TTS Multilingue

Station Abyssale-6 est un jeu d'aventure immersif qui combine une interface graphique Java avec une narration textuelle.
Le joueur incarne un survivant dans une station de recherche sous-marine en perdition à 1000 mètres de profondeur. Objectif : rétablir le courant avant que l'oxygène ne s'épuise (timer 10 minutes). Échangez avec les PNJ, collectez des objets, résolvez le puzzle du réacteur et utilisez le Beamer pour vous téléporter !

🌟 NOUVEAUTÉS : Support multilingue complet (🇫🇷 🇬🇧 🇩🇪 🇨🇳), synthèse vocale adaptative, dialogues PNJ générés par IA locale (LLM).

🔧 Dépannage Rapide

❌ Accents mal prononcés
→ Mettre à jour la version avec support UTF-8
❌ Voix allemande absente
→ Installer pack linguistique DE dans Windows
❌ PNJ répond en anglais
→ Vérifier paramètre "language" dans requête API
❌ LLM trop lent
→ Utiliser modèle 1B ou réduire temperature

🌀 MÉCANIQUES SPÉCIALES

📡 Beamer (téléporteur)

Chargez le Beamer dans une pièce (charge), puis utilisez fire pour y retourner instantanément.

🍪 Magic Cookie

Augmente définitivement la capacité de portage de +13 kg. Obtenu via échange avec le docteur.

🔋 Torche & Easter Egg

Dans l'Observatoire, utilisez la torche (use torche) avec batterie >15% pour révéler un secret.

🌀 Transporter Room

Pièce spéciale qui téléporte aléatoirement. Commande alea [roomKey] (mode test).

🧩 Puzzle du réacteur

Atteignez la salle du réacteur pour activer le puzzle électrique (8 interrupteurs, voltmètre).

💾 Sauvegarde XML

save nom / load nom : tout l'état (pièces, inventaire, langue active) est sauvegardé.

🏗️ STRUCTURE DU PROJET (Java)

Packages principaux

🎮 pkg_core

GameEngine, GameGUI, Parser – cœur du jeu, gestion des commandes, timer, transitions.

🗺️ pkg_gameplay

Room, Door, TransporterRoom – gestion des salles, portes verrouillées, téléportation.

👥 pkg_characters

Player, Character, MovingCharacter – inventaire, poids, déplacement, dialogues LLM.

📦 pkg_items

Item, Beamer, MagicCookie, DivingSuit, Torch – types, poids, images, utilisabilité.

🖥️ pkg_ui_components

TransitionPanel, InventoryPopup, EasterEggDialog, PuzzlePage – interface interactive.

⚙️ pkg_utility

Lang (i18n), MusicPlayer, GameSaverXML, SapiTTS (multilingue) – internationalisation, sons, sauvegarde, synthèse vocale.

⌨️ COMMANDES DISPONIBLES

go nord/sud/est/ouest/haut/bas look inventory take <objet> drop <objet> eat <cookie> back use <objet> charge fire talk [nom] give <objet> save <fichier> load <fichier> lang fr/en/de/zh test <script> alea [room] tts on/off help quit

✨ Les PNJ réagissent aux objets donnés (échanges) et fournissent des indices via LLM.
✨ Commande lang change interface, dialogues IA et voix TTS instantanément.
