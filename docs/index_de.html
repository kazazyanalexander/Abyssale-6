⏦ Abyssal Station‑6 ⏦

⚡ PROJEKT: MEHRSPRACHIGES TEXTADVENTURE MIT KÜNSTLICHER INTELLIGENZ ⚡
🌍 Deutsch 🌍 English 🌍 Français 🌍 中文 🤖 Lokaler LLM 🎤 Mehrsprachige TTS

Abyssal Station-6 ist ein immersives Abenteuerspiel, das eine grafische Java-Oberfläche mit textbasierter Erzählung kombiniert.
Sie spielen einen Überlebenden in einer havarierten Unterwasserforschungsstation in 1.000 Metern Tiefe. Ziel: Stellen Sie die Stromversorgung wieder her, bevor der Sauerstoff zur Neige geht (10-Minuten-Timer). Tauschen Sie mit NPCs, sammeln Sie Gegenstände, lösen Sie das Reaktor-Rätsel und benutzen Sie den Beamer zum Teleportieren!

🌟 NEUE FUNKTIONEN: Vollständige Mehrsprachigkeit (🇫🇷 🇬🇧 🇩🇪 🇨🇳), adaptive Sprachsynthese, KI-generierte NPC-Dialoge (lokales LLM).

🌍 VOLLSTÄNDIGE MEHRSPRACHIGKEIT

🗣️ Text-to-Speech (TTS)

4 unterstützte Sprachen: Deutsch, Englisch, Französisch, Chinesisch.
Stimmen werden automatisch basierend auf der Spielsprache ausgewählt:
🇩🇪 Stefan/Hedda · 🇬🇧 David/Zira · 🇫🇷 Paul/Hortense · 🇨🇳 Kangkang/Huihui
✅ UTF-8 Unterstützung · ✅ Intelligente Fallback-Funktion

🧠 Lokaler LLM (LangGraph)

Dynamische Dialoge generiert von maitre-granite-3.2-2b-instruct
• Separate Agenten pro Sprache (unabhängiger Speicher)
• Kontextuelle und kohärente Antworten
• FastAPI + LangChain Integration
✅ 4 Agenten pro NPC (1 pro Sprache)

🎮 Dynamischer Wechsel

Befehl lang de/en/fr/zh
• Oberfläche sofort übersetzt
• LLM-Dialoge in neuer Sprache
• TTS wechselt automatisch
• Einstellung wird gespeichert

🔧 Schnelle Fehlerbehebung

❌ Akzente falsch ausgesprochen
→ Auf neueste Version mit UTF-8-Unterstützung aktualisieren
❌ Deutsche Stimme fehlt
→ Deutsche Sprachpaket in Windows installieren
❌ NPC antwortet auf Englisch
→ "language"-Parameter in API-Anfrage prüfen
❌ LLM zu langsam
→ 1B-Modell verwenden oder Temperatur senken

🌀 SPEZIELLE MECHANIKEN

📡 Beamer (Teleporter)

Laden Sie den Beamer in einem Raum (charge), dann verwenden Sie fire für sofortige Rückkehr.

🍪 Magischer Keks

Erhöht dauerhaft die Tragfähigkeit um +13 kg. Erhältlich durch Handel mit dem Arzt.

🔋 Taschenlampe & Easter Egg

Im Observatorium, benutzen Sie die Taschenlampe (use taschenlampe) mit Batterie >15%, um ein Geheimnis zu enthüllen.

🌀 Transporterraum

Spezieller Raum mit zufälliger Teleportation. Befehl alea [raum] (Testmodus).

🧩 Reaktor-Rätsel

Erreichen Sie den Reaktorraum, um das elektrische Rätsel zu aktivieren (8 Schalter, Voltmeter).

💾 XML-Speichersystem

save name / load name: Speichert den gesamten Zustand (Räume, Inventar, aktive Sprache).

🧾 ZIEL & INNOVATIONEN

Schaffung eines immersiven Erlebnisses, das Textadventure, dynamische Grafiken, handelnde NPCs, Gewichtssystem, Rätsel und Teleportation vereint.
Hauptinnovationen: 4-Sprachen-Unterstützung, lokale KI für Dialoge, adaptive TTS.

🏗️ PROJEKTSTRUKTUR (Java)

Hauptpakete

🎮 pkg_core

GameEngine, GameGUI, Parser – Spielkern, Befehlsverarbeitung, Timer, Übergänge.

🗺️ pkg_gameplay

Room, Door, TransporterRoom – Raumverwaltung, verschlossene Türen, zufällige Teleportation.

👥 pkg_characters

Player, Character, MovingCharacter – Inventar, Gewicht, Bewegung, LLM-Dialoge.

📦 pkg_items

Item, Beamer, MagicCookie, DivingSuit, Torch – Typen, Gewicht, Bilder, Verwendbarkeit.

🖥️ pkg_ui_components

TransitionPanel, InventoryPopup, EasterEggDialog, PuzzlePage – interaktive Oberfläche.

⚙️ pkg_utility

Lang (i18n), MusicPlayer, GameSaverXML, SapiTTS (mehrsprachig) – Internationalisierung, Sound, Speichern, Sprachsynthese.

⌨️ VERFÜGBARE BEFEHLE

go norden/süden/osten/westen/oben/unten look inventory take <gegenstand> drop <gegenstand> eat <keks> back use <gegenstand> charge fire talk [name] give <gegenstand> save <datei> load <datei> lang de/en/fr/zh test <skript> alea [raum] tts on/off help quit
