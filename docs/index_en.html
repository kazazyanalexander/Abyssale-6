⏦ Abyssal Station‑6 ⏦

⚡ PROJECT: MULTILINGUAL TEXT ADVENTURE GAME WITH AI ⚡
🌍 English 🌍 French 🌍 German 🌍 Chinese 🤖 Local LLM 🎤 Multilingual TTS

Abyssal Station-6 is an immersive adventure game that combines a Java graphical interface with text-based narration.
You play as a survivor in a failing underwater research station at 1,000 meters depth. Objective: restore power before oxygen runs out (10-minute timer). Trade with NPCs, collect items, solve the reactor puzzle, and use the Beamer to teleport!

🌟 NEW FEATURES: Full multilingual support (🇫🇷 🇬🇧 🇩🇪 🇨🇳), adaptive text-to-speech, AI-generated NPC dialogue (local LLM).

🌍 COMPLETE MULTILINGUAL SUPPORT

🗣️ Text-to-Speech (TTS)

4 supported languages: English, French, German, Chinese.
Voices automatically selected based on game language:
🇬🇧 David/Zira · 🇫🇷 Paul/Hortense · 🇩🇪 Stefan/Hedda · 🇨🇳 Kangkang/Huihui
✅ UTF-8 support · ✅ Intelligent fallback

🧠 Local LLM (LangGraph)

Dynamic dialogues generated by maitre-granite-3.2-2b-instruct
• Separate agents per language (independent memory)
• Contextual and coherent responses
• FastAPI + LangChain integration
✅ 4 agents per NPC (1 per language)

🎮 Dynamic Switching

Command lang en/fr/de/zh
• Interface immediately translated
• LLM dialogues in new language
• TTS automatically switches
• Preference saved

🔧 Quick Troubleshooting

❌ Accents mispronounced
→ Update to latest UTF-8 supported version
❌ German voice missing
→ Install German language pack in Windows
❌ NPC replies in English
→ Check "language" parameter in API request
❌ LLM too slow
→ Use 1B model or lower temperature

🌀 SPECIAL MECHANICS

📡 Beamer (Teleporter)

Charge the Beamer in a room (charge), then use fire to instantly return.

🍪 Magic Cookie

Permanently increases carrying capacity by +13 kg. Obtained through trade with the doctor.

🔋 Torch & Easter Egg

In the Observatory, use the torch (use torch) with battery >15% to reveal a secret.

🌀 Transporter Room

Special room that teleports randomly. Command alea [roomKey] (test mode).

🧩 Reactor Puzzle

Reach the reactor room to activate the electrical puzzle (8 switches, voltmeter).

💾 XML Save System

save name / load name: saves entire state (rooms, inventory, active language).

🏗️ PROJECT STRUCTURE (Java)

Main Packages

🎮 pkg_core

GameEngine, GameGUI, Parser – game core, command handling, timer, transitions.

🗺️ pkg_gameplay

Room, Door, TransporterRoom – room management, locked doors, random teleportation.

👥 pkg_characters

Player, Character, MovingCharacter – inventory, weight, movement, LLM dialogues.

📦 pkg_items

Item, Beamer, MagicCookie, DivingSuit, Torch – types, weight, images, usability.

🖥️ pkg_ui_components

TransitionPanel, InventoryPopup, EasterEggDialog, PuzzlePage – interactive interface.

⚙️ pkg_utility

Lang (i18n), MusicPlayer, GameSaverXML, SapiTTS (multilingual) – internationalization, sound, save, speech synthesis.

⌨️ AVAILABLE COMMANDS

go north/south/east/west/up/down look inventory take <item> drop <item> eat <cookie> back use <item> charge fire talk [name] give <item> save <file> load <file> lang en/fr/de/zh test <script> alea [room] tts on/off help quit

✨ NPCs react to given items (trading) and provide clues via LLM.
✨ lang command instantly changes interface, AI dialogues, and TTS voice.
